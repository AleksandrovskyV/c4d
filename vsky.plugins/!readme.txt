Place the "GlobeDeformer" folder into your Cinema 4D plugin directory

Cinema 4D R19 - R23 (program path): 
C:\Program Files\MAXON\Cinema 4D R##\plugins\GlobeDeformer

Cinema 4D 2026 (preference path):
The resulting path should look like this:
...\AppData\Roaming\Maxon\Cinema 4D 2026_########\plugins\GlobeDeformer\
